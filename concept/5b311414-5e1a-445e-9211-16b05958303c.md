## Статус: ЖИВОЕ свойство, семантика materialized-OR-computed

⛔ **Деприкация снята 2026-09-27 — она противоречила approved-RFC `b860de33`.** Свойство было
дуально типизировано `exo__DeprecatedProperty`, и 2026-09-27 к этому был дописан
`exo__DeprecatedProperty_useInstead → concept__Concept_differentia`. Оба снято: ни то, ни другое
не выводилось ни из одного решения, а RFC говорит прямо противоположное.

## Что говорит RFC `b860de33` (approved, Delta-1 applied 2026-07-26)

§«Изменения существующих», дословно:

> `concept__Concept_definition` (`5b311414`) → семантика **materialized-OR-computed**
> (⛤ РЕВИЗИЯ, **НЕ blanket-retire**): computed (рендерится из genus+differentia, Delta-2) где
> реконструируется (~30 %); **stored сохраняется** где нарратив/перечисление/контраст/расшифровка
> (~70 %). **Backward compat:** не ломает инстансы (**свойство остаётся**).

§«Retire (dual-type `exo__DeprecatedProperty` + `_useInstead`)» перечисляет **ровно два**
свойства — `concept__Concept_broader` и `concept__Concept_schema`. Этого свойства там **нет**.

§«Альтернативы», вариант D:

> **blanket definition-retire (исходный F1). Отклонён** — ~70 % определений несут неустранимый
> контент → потеря. `materialized-OR-computed` сохраняет нарратив.

§«Решение фаундера (2026-09-06)»: остаток ретайра — **48 записей** (`broader` 46 + `schema` 2).
Этого свойства в остатке тоже нет.

## Почему `differentia` НЕ может быть преемником

`concept__Concept_differentia` (`5cc92949`) — **ObjectProperty**, `range = concept__Concept`,
cardinality 0..N: это **ссылки на концепты**, а не текст. Здесь же `range` = `30d63ce4`
(строковый тип). Замена одного другим невыразима: у ~70 % носителей содержимое — нарратив,
который ссылками не представим, и именно это измерил адверсарный гейт RFC
(«из 25 определений только ~30 % реконструируются из genus+differentia»).

## Как это поле работает

- **stored** — там, где `concept__Concept_genus` не задан либо содержимое нарративно. Это
  законный и основной режим: замер 2026-09-27 по трём vault (с дедупом) — **371** носитель, из
  них **146** вообще без `genus`.
- **computed** — там, где genus+differentia заполнены; рендер описывает
  `concept__ConceptDefinitionSpec` (`26358178`), сборка идёт `exo__DisplayNamePart` /
  `exo__PrintedProperty`, семантика fail-closed (нет чистого genus-лейбла → не фабрикуем).

⚠ Целевые структуры наполнены слабо: `differentia` — **8** носителей, `concept__ConceptDefinition`
— **9** (замер 2026-09-27, три vault, дедуп). Инстанс-разбор ~3354 концептов RFC выносит в
**Delta-3** — отдельный gated-этап, не следствие этой пометки.

## Что из этого следует для issue #4358

Issue утверждал, что создание концепта пишет в **deprecated** предикат. Пометка снята как
ошибочная ⇒ `ConceptCreationService` пишет в **законное** поле, и дефекта «пишет в deprecated»
не существует. Открытой остаётся вторая, независимая претензия: сама семантика создания
захардкожена в TypeScript вместо RDF (Homoiconicity Invariant Q1) — она закрывается переводом
команды на `create_instance` + `property_set`, и это отдельная работа.
